# Sprint 7 Report (10/12/25 - 11/8/2025)
## What's New (User Facing)
* Application has a new 'Comparison' tab at the top for a more advanced analysis comparison between datasets
* Application removed the 'Crater Volume' tab
* Application refactored the entire 'Analysis' tab to perform different analysis computations
 
## Work Summary (Developer Facing)
During this sprint, the team spent the first week manually annotating a ground-truth dataset for further comparison into the accuracy of our developed SAM model. Once the annotations were complete, the team moved into a large refactoring of the GUI. The Crater Analysis tab was removed and replaced by a new Comparison tab. The Analysis tab was completely redone. Instead of allowing the User to select which PDFs to test the accuracy of and then generate the PDF graph of the dataset, the Analysis now runs a predetermined set of PDFs and creates a bar chart to display the respective probabilities of each PDF for the dataset. It then takes the most likely PDF and uses the specific PDF parameters to map all possible plotted functions. It then plots the average for a visual analysis. From here, the dataset is transferred to the Comparison tab, where the User will be able to select two datasets generated by the Analysis to plot the graphs for comparison, as well as compute a single KL Divergence value that indicates similarity between the two. This is the core value that the GUI is expected to accurately produce.
