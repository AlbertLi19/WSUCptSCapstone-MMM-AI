# Sprint 4 Report (4/5/24 - 5/4/2024)

## What's New (User Facing)
 * An overall more functional impurity program for statistical analysis

## Work Summary (Developer Facing)
In this sprint, we continued on making improvements in each of our respective areas in the project, while overall providing better documentation and updates to Dr. Zare. Lee worked on data analysis where he compared impurity data from the client's previous matlab script findings to the current from the python script, updating the program to accomodate more images and work with histograms. A large emphais is on determining each histogram's probability density function as accurately as possible, which requires some research into various python libraries capable of doing so. Book ventured into edge-based segmentation as a potential alternative to watershed while also continuing to work on watershed to get it as accurate at identifying pores as possible, with varying success. Finally, Takada continues research on ML for segmentation through SAM and Roboflow while also reaching out to WSU's Kamiak for greater processing power to supplement these models.
