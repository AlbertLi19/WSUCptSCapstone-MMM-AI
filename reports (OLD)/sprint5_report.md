# Sprint 5 Report (8/19/2024 - 9/13/2024)

## What's New (User Facing)
* GUI outline that allows the user to insert images
* Python script that data mines from images
* Python script that determines the best fit statistical model and generates data based on the model
## Work Summary (Developer Facing)
In this sprint, we pivoted from focusing on pore image analysis and impurities to only impurities. For the impurities, we focused on developing data mining techniques to gather data from various other scientific papers for our datasets. In addtion, we created a Python-based GUI for the end user to interact with by selecting a set of images and updating parameters within the interface. Finally, progress is being made in creating a script to find the relationship between the impurity size and the material strength.

Unfinished work in this sprint includes generating the data-driven model workflow in Orange. This was due to inexperience with statistical models and data aggregation
